## 比較案

最初のA・B案について「元のデザインのほうがよい。鮮やかで印象的な色と角丸がよい」と回答をいただき、現行を基準にC・D案を作成しました。比較画面には現行・C・Dを並べています。

| ---- | ---------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------- |

| C    | 現行の配色と角丸を維持                         | Noto Sans JP、Echo.は従来のArial | 上部の余白を詰め、日程・会場・主要操作を早く表示。スポンサーを4段階のサイズに分ける         |

## スポンサー4段階

既存データの大口5件、1ページ3件、4分の1が8件、8分の1が71件を維持しています。区分名は比較操作にだけ表示し、サイト本文には追加していません。

PCは大口から順に2・3・4・5列とし、画面が狭い場合は列数と枠幅を調整します。360px幅では全区分を1列とし、表示枠を大口から順に100%・94%・87%・80%にしています。広告は全体を表示し、ロゴ・広告の色、順序、名称、リンク先は変更していません。

## 確認結果と未実施事項

- 静的HTMLは現行・A・B・C・Dのホームとスポンサー計10コピーで、body全体、本文、href、画像とalt、見出し、メタ情報が完全一致しています。比較用CSSと時計固定用スクリプトだけをheadへ追加しています。
- 現行・C・Dのホームとスポンサーを320・360・768・1280pxで確認しました。スポンサーの320pxは今回の記録対象外です。計21画面で本文・リンク・画像の一致と横はみ出しなしを確認しました。
- C・Dとも360・768・1280pxで、大口から8分の1へ表示枠が順に小さくなることを実測しました。4段階それぞれのスクリーンショットも保存しています。
- A・B・C・Dは既存26組のコントラスト基準を満たしています。Dの青い上部は白文字で、通常の文字との比率は6.00:1です。
- Dのモバイルメニューの開閉も確認しました。
- `npm run check`は成功しました。48件のテスト、原素材140件、広告87件、地図9件、公開用HTML10件の既存チェックを含みます。
- Lighthouse、全機能のE2E、文字200%拡大、全9ページの公開前の出典照合は、この比較段階では完了していません。合格済みとして扱いません。

## 再表示と出力

```sh
npm run build
node scripts/design-review.mjs
node scripts/design-review-check.mjs
node scripts/design-review.mjs --serve
```

表示先は`http://127.0.0.1:4186/__design-review__/`です。比較用の時計は日本時間2026年10月22日10:00に固定し、動きを止めています。既存の時計の実装やOSの時刻設定は変更していません。

スクリーンショットと検証記録は`tmp/design-review/`に保存しています。保存版の比較画面`comparison.html`は画像をすべて内包するため、サーバーなしでも開けます。画面幅とスポンサー区分を切り替えられます。

フォントを再生成する場合は、公式配布元のフォントとライセンスを`tmp/design-review/references/`へ取得し、fontToolsとBrotliを利用できるPythonで`scripts/design-review-fonts.py`を実行してください。現在の環境では`tmp/fonts/venv/bin/python`を使用しました。

全ページへの適用、コミット、push、公開は行っていません。
