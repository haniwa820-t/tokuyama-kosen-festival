## 更新手順

1. 原素材を`assets/source/`に保持し、`assets/source/manifest.json`に容量とSHA-256を記録します。
2. `src/data/sponsor-banners.json`の名称、区分、出典、画像、確認日を更新します。リンクは大口5社にだけ設定します。
3. macOSのSwift/PDFKitが使える環境で`npm run assets:provided`を実行します。レンダー済みPDF画像は`tmp/supplied-assets/`に保管します。原稿を差し替える際は、その原稿のレンダーキャッシュを削除してから再実行してください。
4. 生成した`public/images/sponsors/`の画像もGitで管理し、`npm run check`と`npm run test:e2e`で確認します。

`npm run assets:sponsors`は旧サンプル画像の生成処理です。提供画像の使用中は停止して、掲載データの上書きを防ぎます。
