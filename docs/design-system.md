# Echoのデザイン要件

2026-10-08更新。対象は第52回徳山高専高専祭の9ページ。来場者が日程・企画・場所を見つけ、当日もスマートフォンで使えることを優先する。

## 原則

1. 学生の表現を主役にする。提供メインロゴと企画ポスターを用い、新しい文字ロゴや架空の写真で置き換えない。
2. 日時と次の行動を先に見せる。ホームはロゴ・開催日時・場所・日程への導線、カウントダウン、企画・地図・PDFの順に案内する。
3. 操作を予測できるようにする。同じ役割のリンク・ボタン・選択状態を全ページで揃え、共通メニューとパンくずで現在地とホームへの道を示す。
4. 装飾は必要な場所に絞る。日本語を中心にし、通し番号・装飾英文・回転するポスター・動き続ける背景・重い影を用いない。
5. 色だけで意味を伝えない。選択は下線・文字・aria属性と併用し、保存済み、在校生限定、準備版を言葉で示す。

## ロゴ

提供ファイル`assets/source/メインロゴ.jpg`の、黒い外側余白を除いた既存の公開用コピー`public/images/echo-logo.webp`を使用する。図案・色・縦横比を変更しない。
`src/components/Logo.tsx`でヘッダー、トップ、フッターの表示を統一。ヘッダーのロゴはホームへのリンクで、学校名の本文と「ホーム」メニューも並べる。
faviconは同じ画像から余白付きPNGへ縮小する。AI生成・他校素材・仮のe.ロゴは使わない。

## 色の役割

実装値は`src/styles/tokens.css`。メインロゴから色相を選び、画面の用途に合わせて明度を調整した。下記の数値は実装した配色の計測値で、参考サイトのコピーではない。

| トークン | 色 | 用途 | 主な背景とのコントラスト |
| --- | --- | --- | --- |
| `color-text` | `#193247` | 本文・見出し | 白で13.22:1 |
| `color-text-muted` | `#526577` | 注記・補助文 | 白で6.02:1 |
| `color-action` | `#005d85` | リンク・主要ボタン・選択 | 白で7.23:1 |
| `color-action-hover` | `#004461` | 操作のhover | 白文字で10.50:1 |
| `color-gold` | `#f6cc60` | 見出しの小さな線・時計数字 | 青で4.73:1 |
| `color-accent` | `#ef9a35` | 装飾・案内の印 | 本文用には使わない |
| `color-surface` | `#ffffff` | 読む面 | — |
| `color-surface-subtle` | `#f4f7f9` | 日程・補助領域 | 補助文で5.60:1 |
| `color-surface-blue` | `#e8f3f8` | 操作群・現在地 | 青文字で6.41:1 |
| `color-surface-warm` | `#fff3d4` | 開催概要・注意 | 注意文字で7.15:1 |
| `color-warning-text` | `#843d16` | 準備版・限定案内・保存済み | 淡黄で7.15:1 |
| `color-focus` | `#b04718` | キーボードフォーカス | 白で5.58:1 |
| `color-control-border` | `#718393` | 入力・操作部の輪郭 | 白で3.91:1 |

通常文字の組み合わせは4.5:1以上、操作の輪郭・フォーカスは3:1以上を設計の下限とする。元のロゴやポスターのピクセルは変更せず、主要事項をHTMLの本文にも掲載する。

## 文字と余白

- 本文16px（1rem）、補助文14px、企画タイトル18px、見出し24〜40px。モバイルのヘッダー補足・時計単位は12px。長文の行間は1.8。
- 日本語の端末標準ゴシックを使用。外部フォントを読み込まず、見出しは700、本文は400とし、文字間を広げすぎない。
- 4pxを基礎に8・12・16・24・32・40・48・64・80pxの余白を定義する。通常の横余白はPC32px、モバイル20px。
- 本文領域は最大1200px。heroは1280px。文章は読み幅を絞り、余白は情報のまとまりを区別するために使う。

## 部品と状態

| 部品 | 共通ルール |
| --- | --- |
| ナビゲーション | ホームを先頭に、ページ名は日本語。現在地は淡青・下線・`aria-current`。ヘッダーを固定し、1100px以下は開閉メニューへ |
| 主要ボタン | 青地＋白文字、高さ48px以上、角6px、hoverは濃青。ページ移動はリンク、画面操作はbutton |
| 補助操作 | 白地＋操作用の輪郭、青文字。保存ボタンや本文リセットは高さ44px以上 |
| 無効状態 | 薄いグレーと補助文字色、disabled属性。選べる企画が0件のときはおまかせを無効にする |
| 選択状態 | 日程・分類は青地＋白文字と`aria-pressed`。保存済みは淡黄＋「保存済み」＋塗りつぶしのハート |
| 入力 | 高さ48px、16px文字、ラベルを外に表示。placeholderだけで説明しない |
| 企画 | ポスターを変形せずcontain表示、団体・企画名・場所・保存を同じ順にする |
| 案内リンク | 文字と薄い罫線で区切る。装飾的な影やhover時の大きな移動は使わない |
| 注意表示 | 淡黄＋濃茶、準備版・在校生限定を文字で表示 |
| 詳細・通知 | オーバーレイだけに弱い影。閉じる操作、Escape、フォーカス復帰、状態の読み上げを維持 |

## 動きと画面幅

フェードは360ms・移動12px、hoverは160ms。常時アニメーションは使わない。`prefers-reduced-motion`では停止し、JavaScriptなしでも案内とPDFを読める。
320・768・1024・1440pxでホームの横はみ出しとロゴ・ホーム導線を確認し、全階層はPCとスマートフォンの両方で直接アクセス・再読込を確認する。

## 検証と更新

- `npm run check:design`：役割別の12組のコントラストを計算。色を変更したときの読みにくさを検出する。
- `npm run check`：型・lint・39件の単体/画面操作テスト・出典・配色・ビルド・内部リンクを確認する。
- `npm run test:e2e`：PC・スマートフォン合計16件。既存機能、ホームメニュー、ロゴ、主要メニューの44px以上の高さ、画面幅などを確認する。
- CSSは追記で上書きを重ねず、トークンと部品の定義を直接更新する。
