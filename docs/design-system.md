# Echoのデザイン要件

2026-10-22更新。ユーザーが比較画面で選んだD案を、全9ページに適用する。学生のポスター・ロゴと調和する鮮やかな青とピンク、丸みのある面、読みやすいゴシックを使う。

## 情報の保護

今回の変更対象はCSSとフォント。本文、href、画像ファイル、alt、見出し階層、HTMLの順序、メタ情報、検索・保存・おまかせ・カウントダウンの機能は維持する。区分名や宣伝文句は追加しない。

提供素材と徳山高専の公式情報を出典とし、ユーザーによる訂正を優先する。他校の文章・素材・コード・固有の配色やレイアウトはコピーしない。

## 色

共通の色は`src/styles/tokens.css`、適用は`src/styles/global.css`で管理する。

| 役割 | 色 | 用途 |
| --- | --- | --- |
| 本文・濃い面 | `#102f56` | 本文、見出し、カウントダウン・フッターの背景 |
| 操作色 | `#285dc9` | リンク、選択、ホーム上部、大口スポンサーの名称欄 |
| 操作時の濃い青 | `#1947a8` | hover |
| アクセント | `#fca8dd` | Echo.の点、時計数字、おまかせ操作 |
| ページ背景 | `#f7f8fc` | わずかに青みのある地 |
| 白い面 | `#ffffff` | 広告・ポスターの枠、ヘッダー、案内 |
| 淡青の面 | `#e6edff` | 操作群、案内、現在地 |
| 淡いピンク | `#ffe9f5` | 注意・保存済みの背景 |
| 補足文字 | `#4b5d75` | 注記 |
| 注意文字 | `#853660` | 注意表示 |
| フォーカス | `#c56898` | 明るい面・紺の面のフォーカスリング |

ポスターの青`#4a8cec`を出発点に、文字・操作のコントラストに合わせて青を調整した。ピンク`#fca8dd`はポスターから抽出した値。抽出位置とWeb調査は[比較記録](../design-review/README.md)を参照する。

青地の文字は白で6.00:1、ピンク地の文字は紺で7.54:1。通常文字は4.5:1以上、操作の輪郭・フォーカスは3:1以上を下限とする。ホーム上部の白いボタンには白のリング、白いポスター枠のリンクには紺のリングを使う。

## 書体

本文・見出し・操作はNoto Sans JPの可変フォントを使う。明朝体は使用しない。フォールバックはHiragino Sans、Yu Gothic、Meiryo、sans-serif。本文400、補足見出し500、操作600、見出し700、ページ見出し800を基本とする。

書体の選定では[神戸高専祭2026](https://www.kcctfes.jp/)と[Science Tokyoの書体ガイド](https://design-system.isct.ac.jp/ja/brand/elements/typography)でNoto Sans JPの採用を確認した。Echo.は従来のArialの太い斜体、日付・時計数字も従来のArialを維持する。

フォントはGoogle Fontsの公式配布から取得し、サイトのTS・TSX・JSONの使用文字とASCIIを含むWOFF2に変換して自サイトから配信する。検索結果、詳細表示、空の検索結果などの動的な文言も含める。端末への外部フォント配信サービスの接続は不要。元フォントが含まない文字にはフォールバックを使う。

- 公開用フォント：`src/assets/fonts/noto-sans-jp.woff2`、203,776バイト。
- 出典URL・元ファイルと出力のSHA-256・収録文字：`src/assets/fonts/manifest.json`。
- ライセンス：`public/fonts/noto-sans-jp-OFL.txt`。SIL Open Font License 1.1を同梱する。
- 再生成：fonttoolsとBrotliのあるPython環境で`python scripts/prepare-site-font.py <公式配布TTFのパス>`を実行する。公式配布元はmanifestに記録する。新しい文字を追加した場合は収録文字を検証し、必要に応じて再生成する。

## ホームと案内

- 淡い背景の中に、角丸28pxの大きな青い面を配置する。スマートフォンでは角丸24px、1列にする。
- 学校名、Echo.、開催日・時刻、会場、日程へのボタンを先に表示する。ポスターはPCで右、スマートフォンで開催情報の後に配置する。
- 提供メインロゴとポスターの図案・色・縦横比を変えない。ポスターは3度、パンフレット表紙は−3度の静止した傾きを維持する。他の画像や操作は傾けない。
- 同心円はホームの背景に限定し、新しい文言やラベルを装飾として追加しない。
- 主ボタンは青い面の中では白。hoverはピンクと紺文字にする。タップ領域は44px以上を基本とし、ホーム主ボタンは52px以上。320px幅では左右の余白を減らし、末尾の不自然な折り返しを防ぐ。
- ホームの案内はPCで最初の枠を少し広くし、スマートフォンは縦に並べる。
- 操作の角丸は12px、案内・検索・スポンサーなどの面は20pxを基本とする。影はポスター・パンフレットとオーバーレイに限定する。

## スポンサー

既存の4段階、掲載順、広告87件、大口5社のURL、協賛一覧100件を維持する。画面へ区分名を追加せず、枠の大きさと余白で違いを示す。

| 既存データの区分 | PCの列数 | 760px以下の枠幅 |
| --- | --- | --- |
| 大口 | 2 | 100% |
| 1ページ | 3 | 94% |
| 4分の1 | 4 | 87% |
| 8分の1 | 5 | 80% |

761〜1100pxでは8分の1を4列・全体幅86%にし、4分の1より小さくする。区分間は罫線と余白で区切る。大口は青い輪郭と白文字の名称欄を使う。すべての広告を`object-fit: contain`で表示し、切り抜きや引き伸ばしをしない。

## 動きと操作

ホームの登場は640msのフェード1種類。ポスターの回転は静止したままにする。スクロールでは情報単位の一度だけの表示を維持し、親子で重ねない。常時動く背景や無限ループは追加しない。

`prefers-reduced-motion`ではアニメーション・遷移・滑らかなスクロールを止める。キーボード移動時は内容をすぐ表示し、JavaScriptがなくても本文・階層リンク・PDFを使えるようにする。保存、検索、日程タブ、詳細表示、Escape、フォーカス復帰、CSPを維持する。

## 変更理由と検証

| 変更 | 理由 |
| --- | --- |
| 色トークンをD案へ統一 | 提供ポスターとの調和と全ページの一貫性 |
| Noto Sans JPを自サイトから配信 | 比較で承認された書体を、外部配信への接続なしで使う |
| ホームの青い面・白文字・丸み | 承認された鮮やかな第一印象と情報の強弱を再現 |
| 日時・主操作・余白の調整 | 小さい画面で開催情報と次の行動を探しやすくする |
| スポンサーを4段階のグリッドへ変更 | 既存の区分をサイズ差で伝え、広告全体を表示する |
| 登場フェードを1種類へ統一 | 装飾の動きを抑え、静止したポスターの配置を保つ |

`npm run check`で型・lint・48件のテスト・原素材140件・配色26組・フォント収録文字・静的生成を確認する。`npm run test:e2e`はPCとスマートフォン計24件で、既存機能、広告・地図・PDF、直接アクセス、動きを減らす設定、4段階のサイズ差を確認する。

変更前のビルドを保存し、`node scripts/check-design-content.mjs <変更前のフォルダ> dist`で10件のHTMLのbody全体、本文、hrefの順序、画像とalt、見出し、メタ情報の完全一致を検証する。出典照合と公開前の記録は[公開前確認](reference/design-d-release.md)を参照する。
