# Echoのデザイン要件

2026-10-08更新。対象は第52回徳山高専高専祭の9ページ。来場者が日程・企画・場所を見つけ、当日もスマートフォンで使えることを優先する。

## 原則

1. 学生の表現を主役にする。提供メインロゴと企画ポスターを用い、架空の写真で置き換えない。ホームはユーザーが添付した以前の画面を基準に、大きな「Echo.」の文字と同心円・斜めのポスターを復元する。
2. 日時と次の行動を先に見せる。ホームは学校名・テーマ・開催日時・場所・日程への導線、カウントダウン、企画・地図・PDFの順に案内する。
3. 操作を予測できるようにする。同じ役割のリンク・ボタン・選択状態を全ページで揃え、共通メニューとパンくずで現在地とホームへの道を示す。
4. 装飾は必要な場所に絞る。本文はゴシック体、生成りの面と紺の罫線を基調とし、同じカード・角丸枠・色付き見出し装飾を増やさない。ホームだけに添付画面の英文と同心円を使う。メインポスターは3度、パンフレット表紙は−3度傾け、薄い影を使う。他のポスターや操作部品は傾けない。
5. 色だけで意味を伝えない。選択は下線・文字・aria属性と併用し、保存済み、在校生限定、準備版を言葉で示す。

## ロゴ

提供ファイル`assets/source/メインロゴ.jpg`の、黒い外側余白を除いた既存の公開用コピー`public/images/echo-logo.webp`を使用する。図案・色・縦横比を変更しない。
`src/components/Logo.tsx`でヘッダーとフッターの表示を統一。テーマ紹介にも提供画像を掲載。ヘッダーのロゴはホームへのリンクで、学校名の本文と「ホーム」メニューも並べる。ホームの大きなEcho.はユーザー指定画面のタイトル表現で、学校の公式ロゴとしては扱わない。
faviconは同じ画像から余白付きPNGへ縮小する。AI生成・他校素材・仮のe.ロゴは使わない。

## 文字と余白

- 本文16px（1rem）、補助文14px、企画タイトル18px、見出し24〜40px。ホームの学校名20px（モバイル18px）、キャッチコピー24〜29px。モバイルのヘッダー補足・時計単位は12px。長文の行間は1.8。
- 本文・見出し・操作部品はすべて端末標準ゴシック。日本語の見出し700、本文400。明朝体・追加Webフォントと生成スクリプトは撤去した。
- 添付画面のEcho.だけArialの太い斜体で組む。PC105〜180px、モバイル112〜150px。日本語の本文・見出しには斜体を使わない。
- 4pxを基礎に8・12・16・24・32・40・48・64・80pxの余白を定義する。通常の横余白はPC32px、モバイル20px。
- 本文領域は最大1200px。heroは1160px。文章は読み幅を絞り、余白は情報のまとまりを区別するために使う。

## 部品と状態

| 部品 | 共通ルール |
| --- | --- |
| ナビゲーション | ホームを先頭に、ページ名は日本語。現在地は下線・`aria-current`。ヘッダーを固定し、1100px以下は開閉メニューへ |
| 主要ボタン | 紺地＋白文字、高さ48px以上、角は四角、hoverは濃紺。ページ移動はリンク、画面操作はbutton |
| 補助操作 | 生成り＋操作用の輪郭、紺文字。保存ボタンや本文リセットは高さ44px以上 |
| 無効状態 | 薄いグレーと補助文字色、disabled属性。選べる企画が0件のときはおまかせを無効にする |
| 選択状態 | 日程・分類は青地＋白文字と`aria-pressed`。保存済みは淡黄＋「保存済み」＋塗りつぶしのハート |
| 入力 | 高さ48px、16px文字、ラベルを外に表示。placeholderだけで説明しない |
| 企画 | ポスターを変形せずcontain表示、団体・企画名・場所・保存を同じ順にする |
| 案内リンク | 文字と薄い罫線で区切る。装飾的な影やhover時の大きな移動は使わない |
| 注意表示 | 淡黄＋濃茶、準備版・在校生限定を文字で表示 |
| メインビジュアル | PCは左に学校名・Echo.・日時、右に白い縁取りのポスター。淡青の同心円を背景に置く。モバイルは開催情報の後にポスター |
| 詳細・通知 | オーバーレイには弱い影。閉じる操作、Escape、フォーカス復帰、状態の読み上げを維持 |

## 動きと画面幅

ホームは本文720ms、ポスター900ms（120ms後に開始）、同心円1600msで一度だけ登場する。スクロールでは情報のまとまりごとに640ms・移動16pxで一度だけフェード。横並びの案内・スポンサーは55ms刻み、最大110msだけずらす。親子を二重にフェードさせない。
hoverは160ms、主要ボタンの矢印は小さく移動する。常時アニメーションは使わない。`prefers-reduced-motion`では停止し、途中で設定を変えた場合もすぐ表示する。キーボードのフォーカス先はフェード待ちにせず表示し、JavaScriptなしでも案内とPDFを読める。
320・768・1024・1440pxでホームの横はみ出しとロゴ・ホーム導線を確認し、全階層はPCとスマートフォンの両方で直接アクセス・再読込を確認する。

## 検証と更新

- `npm run check:design`：役割別の13組のコントラストを計算。色を変更したときの読みにくさを検出する。
- `npm run check`：型・lint・41件の単体/画面操作テスト・出典・配色・ビルド・内部リンクを確認する。
- `npm run test:e2e`：PC・スマートフォン合計16件。既存機能、ホームメニュー、ロゴ、主要メニューの44px以上の高さ、画面幅などを確認する。
- CSSは追記で上書きを重ねず、トークンと部品の定義を直接更新する。
