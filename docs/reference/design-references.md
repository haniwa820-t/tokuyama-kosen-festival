# 他高専サイトの参考と独自制作

確認日：2026-10-08。Chromeで閲覧・画面確認した。以下は情報探索の参考だけで、徳山高専の開催情報の出典ではない。

| サイト | 参考になった一般的な設計原則 | このサイトでの対応 |
| --- | --- | --- |
| [奈良高専・2025](https://nara-kosensai.com/2025/) | 模擬店・展示・ステージ・来場案内を探しやすく分ける | 企画・模擬店・日程・来場ガイドを階層化 |
| [宇部高専・2025](https://www2.ube-k.ac.jp/fes2025/) | 企画の分類と検索、日程の切り替え | 飲食・体験・展示の絞り込みと文字検索、2日間の切り替え |
| [神戸高専](https://www.kcctfes.jp/) | 日時・来場案内を早い段階で見せる | 冒頭に開催日時、会場・PDFへの導線を掲載 |

他高専のコード、文章、写真、イラスト、ロゴ、固有の配色・装飾・レイアウトは使用・再現していない。
ユーザーのデザイン再検討依頼により、提供メインロゴの青・黄・オレンジと白を役割別に採用。学生制作のロゴを中心にし、仮文字ロゴ・常時動く同心円・装飾英文を整理した。
原素材の画像は提供資料からのみ加工。AI生成の写真・イラスト、素材サイトの画像、未確認の広告文は使用していない。

## 追加した来場者向け機能

企画の端末内保存と、絞り込み結果からのランダム選択を独自実装した。検索・分類・日程の切り替えという一般的な考え方を参考にしたが、追加機能が他校にもあると未確認のまま宣伝しない。
スポンサー画像30枚は提供された準備版の名称を用いたオリジナルSVGで、企業ロゴではない。企業公式ページはリンク先と名称確認だけに利用し、広告文・写真・ロゴは取り込まない。出典と更新方法は`docs/sponsors.md`を参照。

## 配色とデザインシステムの再検討

2026-10-08に[神戸高専祭2026](https://www.kcctfes.jp/)を再閲覧。開催日時・場所・案内を主役にする優先順位を参考にした。水色・オレンジの組み合わせや写真主体の配置、黒いずらし影、スライドは再現せず、徳山高専のメインロゴから別の色を選んだ。
[メルカリの公式記事](https://careers.mercari.com/mercan/articles/26192/)と[Mercari Design Blog](https://note.com/mercari_design/n/na159427a730f)から、原則・スタイル・部品を共通化し、コントラストと各操作の状態を揃える考え方を参考にした。メルカリの配色・ロゴ・フォント・部品や公開コードは使用していない。要件と実装の対応は`docs/design-system.md`に記録した。
