## 既知の資料間の相違

今回新たに本文を修正する必要のある相違は見つかっていない。以下は既に記録・報告済みの相違で、既存のユーザー訂正と表示方針を維持する。

- メインポスターにはスタンプラリーの「先着順」が残るが、Web本文はユーザー訂正に従って抽選。公式Instagramの原投稿にも抽選会の案内がある。画像は改変しない。
- IE2の個別ポスターと会場資料には階・教室の相違がある。現在の「教室・管理棟」と「当日の案内をご確認ください」を維持する。
- スポンサーのファイル名・広告内名称・ユーザー確定一覧の表記差、および配布PDFに残る削除前の広告は[スポンサー記録](../sponsors.md)に従う。デザイン変更を理由に名称・PDFを変更しない。
- 過去の制作資料には学生限定の後夜祭、準備版PDF、広告88件・協賛101件の記録が残る。最新のユーザー訂正と現在の掲載データを優先する。

## 検証記録

- `npm run check`：型、lint、48件の単体・画面操作テスト、カバレッジ、原素材・掲載情報、26組の配色、フォントのチェックサム・収録文字・ライセンス、静的生成・内部リンクを確認。
- `npm run test:e2e`：PCとスマートフォンの計24件に成功。日程切り替え、検索・保存・おまかせ・詳細表示、直接アクセス・再読込、地図9枚、広告87件、PDF、JavaScript無効時、動きを減らす設定、CSP、スポンサー4段階のサイズ差を確認。
- 変更前ビルドとの比較：全10件のHTMLでbody全体・本文・順序付きhref・画像とalt・見出し・メタ情報が完全一致。
- Lighthouse：モバイル設定で全9ページのアクセシビリティ100。得点に含まれない既存の指摘として、ヘッダーのホームリンクのaria-labelに表示中の回数・年が含まれない項目がある。名称の変更は今回の対象に含めていない。
- 360px幅の広告枠は大口305px、1ページ約287px、4分の1約265px、8分の1が244px。E2Eでも320・360・768・1280pxの各幅で大小関係と横はみ出しなしを確認。

測定結果・スクリーンショット・変更前ビルドは`tmp/design-release/`に保管し、公開物へ含めない。

## 自己評価

ポスター由来の青・ピンク、提供メインビジュアル、大きなEcho.と同心円を組み合わせた。汎用の青紫グラデーションや発光、装飾英文の追加を避け、提供素材の特徴を中心にした。ロゴを隠した状態でも主題と開催情報が伝わる構成だが、他の学祭と区別できるかは主観的な評価であり、利用者調査で確認した結果ではない。
