# 原素材の保管

作業フォルダで提供された素材をここへ整理しています。
ファイルの内容・名前はそのまま保持し、`manifest.json`に移動前後のパス、容量、SHA-256を記録しています。

- メインポスター：今回の開催情報の一次資料。
- メインロゴ：Echo／あの感動をもう一度の表記とテーマ画像。
- 模擬店ポスター：クラス・部活動・学科企画・展示等の素材。35点を目視確認し、32企画・3学科としてデータ化しました。

- パンフレット：添付された全57ページのPDF。ユーザー回答により準備版として配布。元ファイルは変更しません。

原素材には直接加工を加えず、Web用に圧縮・変換・トリミングしたコピーを`public/`または`src/assets/`へ置いてください。
このフォルダは公開アプリの配布先には含めませんが、GitHubリポジトリが公開なら素材自体はリポジトリで閲覧できます。
